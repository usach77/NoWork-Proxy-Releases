# NoWork Proxy

VPN-клиент для Android с автоматическим выбором рабочего сервера.

[**Скачать APK**](https://github.com/usach77/NoWork-Proxy-Releases/releases/latest)

- Проверка текущего подключения и автоматический выбор рабочего сервера.
- Приоритет WiFi: до 400 мс; резервные LTE-серверы: до 500 мс.
- Проверка после смены Wi-Fi и мобильной сети, в том числе в фоне.
- Подписки, данные о трафике, темы и быстрое включение.

Для подключения нужна подписка провайдера или собственная конфигурация. Выпуски предназначены для Android ARM64.

Устанавливайте обновление поверх существующего приложения, без удаления. Старый канал обновлений сохраняется в [NoWork-Proxy](https://github.com/usach77/NoWork-Proxy/releases).
